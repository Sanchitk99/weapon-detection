# 🔍 Weapon Detection System (YOLOv8)

An end-to-end **computer vision application** that detects weapons such as **guns and knives** in images using **deep learning**.

This project demonstrates the complete ML workflow:
dataset handling, model training, inference, and deployment with a web interface.

---

## 🚀 Features
- Gun detection using YOLOv8
- Knife detection using a specialized model
- Multi-model inference pipeline
- Interactive web UI using Streamlit
- Clean and modular project structure

---

## 🧠 Core Concepts
- Object Detection (YOLOv8)
- Convolutional Neural Networks (CNNs)
- Transfer Learning
- Multi-model inference
- Bounding boxes & confidence scoring

---

## 🛠️ Tech Stack
- Python
- YOLOv8 (Ultralytics)
- PyTorch
- OpenCV
- Streamlit
